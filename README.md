# 🟨 Exercícios de JavaScript — Formação Acadêmica

Bem-vindo(a) ao meu repositório de estudos em JavaScript! Este espaço é destinado ao armazenamento e à organização das atividades práticas desenvolvidas durante o 2º Período do curso de **Sistemas para Internet (UNIESP)**.

atividades_js/

## 🛠️ Tecnologias e Ferramentas

- **Linguagens:** JavaScript (ES6+), HTML5
- **Ambiente de Desenvolvimento:** VS Code
- **Execução:** Navegador Web / Developer Tools (Console)
- **Controle de Versão:** Git & GitHub
- **Apoio ao Aprendizado:** Uso de I.A (Gemini/ChatGPT) para auxílio na resolução de dúvidas, refatoração de código, boas práticas e documentação.
